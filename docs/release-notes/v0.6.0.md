## 本次更新

### 自动备份按操作细分

- 「配置」页面的「自动备份」现在按操作类型分别控制是否在覆盖前创建恢复点：恢复角色配置前、迁移角色配置前、恢复或迁移角色形象前、恢复或迁移肖像前。
- 四个选项默认全部开启，保持此前「每次覆盖都留一份恢复点」的行为。
- 迁移角色配置时保存的来源备份不受开关影响，它承载迁移内容本身，不是防御性备份。
- 关闭选项只影响恢复点，事务日志、暂存写入、写后校验和失败回滚照旧生效。

### 自动备份保留数量

- 每个自动备份功能可以单独设置保留份数，范围 `1～100`，默认 `5` 份。
- 开关开启时可以直接修改份数；关闭后输入框灰显但保留原值，再打开仍然是上次的设置。
- 关闭的功能不触发清理，已有自动备份原样保留到下次开启。
- 刷新备份库时按保留数量自动清理，也可以在设置里点「立即清理」。

### 手动备份与自动备份分开管理

- 自动备份写入备份库的 `automatic/` 子目录，与手动备份在存储上彻底分开，各有各的清理规则。
- 角色备份窗口顶部改为「手动备份」和「自动恢复点」两个页签，默认展示手动备份；自动恢复点不再一恢复就把左侧列表撑开。
- 左侧从下拉选择改为一整列列表，右侧显示详情与文件预览。
- 自动恢复点页签不提供删除按钮，统一由保留数量淘汰。
- 角色形象和肖像页面的备份列表默认隐藏自动恢复点，需要时勾选「显示自动恢复点」。
- 旧备份库中混在手动目录里的自动恢复点，仍按备份内容记录的类型识别，并按自动层规则清理。

### 角色配置手动备份清理

- 新增「手动备份清理」设置：默认关闭，开启后按保留份数淘汰角色配置的手动备份，默认保留 `20` 份。
- 该设置只作用于角色配置的手动备份，角色形象和肖像的手动备份不参与。
- 开启后角色备份窗口的手动页签会显示清理规则提示，避免备份减少时找不到原因。

### 界面细节

- 角色形象和肖像的配置源下拉只显示名称，完整目录移到悬停提示。
- 角色备份窗口左侧列表不再逐行重复「手动备份」字样，自动恢复点仍保留有区分意义的类型说明。
- 恢复角色配置后新生成的恢复点当场出现在「自动恢复点」页签，不需要关掉窗口再打开。
- 页签上的备份数量会随删除即时更新。

## 下载

Windows 用户请下载：

- `FFXIVConfigManager-win-x64.zip`
- `FFXIVConfigManager-win-x64.zip.sha256`

下载后可以使用同页提供的 SHA-256 文件校验压缩包。解压到任意可写目录后运行 `FFXIVConfigManager.exe`，也可以从旧版本的「配置」页面直接更新。

## 使用提醒

- 升级后旧设置文件中的自动备份选项按默认值处理：四类恢复点全部开启，保留数量 `5` 份，手动备份清理保持关闭。
- 自动备份的保留数量只作用于自动恢复点，手动备份在开启「手动备份清理」前不会被自动删除。
- 关闭某个恢复点开关不会删除已有的自动恢复点，也不影响软件设置备份的恢复。
