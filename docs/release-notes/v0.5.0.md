## 本次更新

### 软件更新代理

- 可以在「配置」页面开启软件更新代理。
- 代理连接信息改为在独立窗口中设置，协议、IP 和端口分别选择或填写。
- 支持 HTTP、HTTPS、SOCKS4、SOCKS4A 和 SOCKS5 本地代理。
- 「测试代理」可以使用当前填写的信息连接 GitHub，并显示连接耗时或可执行的修正提示。
- 保存后的代理会立即用于检查 GitHub Release、下载校验文件和下载更新包。
- 关闭代理后恢复为直接连接，但保留已经保存的协议、IP 和端口；再次开启即可继续使用。

### 更新进度

- 下载更新包时显示已下载大小、总大小和百分比，进度条会随实际写入的数据推进。
- 尚未收到下载数据时显示等待状态，避免把网络缓慢误认为程序失去响应。
- 下载量小于 `1 MB` 时使用 `KB` 显示，低速网络下也能看到进度变化。
- 下载完成后明确显示校验、准备和应用更新阶段。

## 下载

Windows 用户请下载：

- `FFXIVConfigManager-win-x64.zip`
- `FFXIVConfigManager-win-x64.zip.sha256`

下载后可以使用同页提供的 SHA-256 文件校验压缩包。解压到任意可写目录后运行 `FFXIVConfigManager.exe`，也可以从旧版本的「配置」页面直接更新。

## 使用提醒

- 代理只用于软件更新，不影响角色配置、备份、恢复或迁移。
- 代理 IP 只能使用 `localhost`、IPv4 回环地址或 IPv6 回环地址。
- 当前支持无需账号和密码的本地代理。
