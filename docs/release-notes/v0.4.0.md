## 本次更新

### 肖像管理

- 新增一级功能「肖像管理」，支持角色、肖像备份区之间的备份、恢复和迁移。
- 一条肖像对应一个独立备份方案，创建时必须填写方案名称和备注。
- 角色列表显示真实套装编号、职业图标、原始套装名称和肖像更新时间。
- 备份区只显示方案名称、备注和备份时间，并支持搜索与二次确认删除。
- 支持切换操作方向，同时保留两栏的数据源和肖像选择。
- 恢复和迁移只更新目标肖像的画面参数，不覆盖目标套装编号、职业、名称和关联。

### 角色形象

- 将角色形象改为左右列表，左栏固定为游戏配置源，右栏默认是备份区并可切换到另一个配置源。
- 显示 `01～40` 全部栏位，明确区分空栏位、有效栏位和无法读取的栏位。
- 支持两个配置源之间直接迁移角色形象。
- 切换操作方向时保留已有选择，覆盖已有栏位前仍会二次确认并创建恢复点。

### 交互与安全

- 统一删除、覆盖和迁移确认状态。切换选择、筛选、搜索、数据源或方向后，按钮和顶部提示会同步复位。
- 迁移预览在来源、目标或迁移范围变化后立即失效，避免使用过期确认。
- 增加肖像来源和目标变化检查、归档重新校验、事务日志、写后校验和失败回滚。

### 文档与许可证

- 重写 README，以用户功能和使用方式为主，将架构、格式和发布说明移至独立文档。

## 下载

Windows 用户请下载：

- `FFXIVConfigManager-win-x64.zip`
- `FFXIVConfigManager-win-x64.zip.sha256`

下载后可以使用同页提供的 SHA-256 文件校验压缩包。解压到任意可写目录后运行 `FFXIVConfigManager.exe`，也可以从旧版本的「设置」页面直接更新。
