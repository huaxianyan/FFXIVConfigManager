## 本次更新

### 肖像备份方案编辑

- 选中有效的肖像备份方案后，卡片右上角会显示编辑按钮。
- 可以在独立窗口中修改方案名称和备注。
- 保存时只更新 Manifest 中的方案名称和备注，不修改 `portrait.dat`、备份 ID、创建时间、来源信息和数据哈希。
- 保存过程使用临时归档、完整校验、原子替换和失败回滚；如果归档在编辑期间发生变化，应用会拒绝覆盖。
- 完整性状态已移至卡片右下角，编辑按钮改为无阴影的扁平样式。

### 界面调整

- 将「配置与存储」页面改名为「配置」。
- 「配置」页面从上到下依次显示软件更新、软件设置备份、配置源和备份存储。
- 角色形象和肖像管理中的「备份区」统一简化为「备份」。
- 修正肖像方案编辑窗口中「保存修改」按钮的文字对齐。

## 下载

Windows 用户请下载：

- `FFXIVConfigManager-win-x64.zip`
- `FFXIVConfigManager-win-x64.zip.sha256`

下载后可以使用同页提供的 SHA-256 文件校验压缩包。解压到任意可写目录后运行 `FFXIVConfigManager.exe`，也可以从旧版本的「配置」页面直接更新。
