## 首个正式版本

- 支持发现和添加多个 FFXIV 配置源。
- 支持角色标记、角色配置扫描和已知文件识别。
- 支持创建、校验、预览、恢复和删除角色配置备份。
- 支持在两个本地角色之间选择配置范围并迁移。
- 覆盖前自动创建恢复点，写入失败时执行事务回滚。
- 支持 Windows 便携发布、单实例运行和本地诊断日志。

## 下载

Windows 用户请下载：

- `FFXIVConfigManager-win-x64.zip`
- `FFXIVConfigManager-win-x64.zip.sha256`
