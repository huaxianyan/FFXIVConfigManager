## 本次更新

- 新增角色形象备份，支持读取 `FFXIV_CHARA_01.dat`～`FFXIV_CHARA_40.dat`。
- 支持按种族、性别和备注筛选、搜索角色形象备份。
- 角色形象备份与原始栏位解耦，恢复时可以重新选择目标栏位。
- 覆盖已有栏位前显示现有形象信息，要求二次确认并自动创建恢复点。
- 角色管理新增「只显示有角色标记」，筛选状态会持久化。
- 调整概览统计和常用功能入口。
