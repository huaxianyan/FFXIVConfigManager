# 软件设置备份格式

软件设置备份固定存放在 `<备份位置>/settings/settings.ffxivconfig-settings.json`，每次创建新备份时先写入临时文件并重新读取校验，校验成功后原子覆盖旧文件，因此不维护历史版本。

备份采用 UTF-8 JSON，记录格式版本、UTC 创建时间、已包含的设置范围、自定义配置源和角色标记。当前支持的范围如下：

- `CharacterAliases`：角色管理中的角色标记。
- `CustomProfiles`：用户添加的自定义配置源。

当前备份库位置不会写入软件设置备份，恢复时也不会被修改，因为该路径属于当前设备的存储选择，而且备份文件本身位于该目录中。

恢复对话框只允许选择备份实际包含的范围，未选择的范围保持不变。如果文件不存在、JSON 无效、格式版本不受支持、范围字段无效，或配置源与角色标记不满足当前数据约束，状态会显示为缺失或损坏，程序不会执行恢复。
